# Security and responsible use

This is a local-first developer preview. It is not a hardened public multi-tenant service. Bind to loopback; do not expose the API to the internet without an independently reviewed authentication, authorization, TLS, limits and privacy design.

Reference voices require permission. Do not use the software for impersonation, fraud, unauthorized cloning or misleading endorsement. The sample reference and generated audio must not be presented as the real speaker's new speech.

Do not upload secrets, voice originals, databases, logs containing personal text, or model weights to issues. Use synthetic reproduction data. Public privacy/abuse concerns may be reported without private details; sensitive reports should use a maintainer-approved private channel once one is configured. This preview has no published private reporting endpoint.

Unsigned desktop artifacts can be blocked by the OS. Do not disable Gatekeeper, SmartScreen or organization policy to run them.
