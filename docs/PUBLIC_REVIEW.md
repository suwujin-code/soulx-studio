## 范围与边界

从先前完整工程复制出独立发布目录，不直接把私人项目归档 ZIP 推送到公开仓库。保留推理源码、工作台、前端、安装器和必要测试；保留上游 Apache-2.0、项目关系和参考音频独立许可说明。

排除了：原品牌复刻参考视频/音乐、微信等上游联系二维码、历史内部归档文档、用户工作区与 SQLite、缓存/模型权重、未独立核对来源的普通话演示音频、字体文件和旧的未清理嵌入安装载荷。公开演示截图只来自本轮实际界面操作，文稿与项目为专门撰写的示例。归档粤语参考音频仍按原文件说明归属，不声称是当前模型生成。

## 可复核

`python scripts/audit_public.py` 输出本次允许公开文件集及风险项，不打印检测到的密钥内容。`python -m pytest tests -q` 复测源码逻辑；`python scripts/build_desktop_installers.py --payload-only` 后运行安装器 Go 测试。真实目标平台 CI 工作流提供为待执行配置，无未实际运行的绿色徽章。

语音模型、依赖安装和 CUDA/MPS 等原有待验证点未因这次公开整理而自动完成。仍应首先用拥有许可的参考声音完成一条约 50 字粤语生成，再验证实际多条文稿、版本保留、重启恢复和导出。

本地 Git 预提交发现忽略规则 `models/` 会误排除推理源码目录；已改为只忽略根目录 `/models/`，新增真实 Git 检查测试，确认源码保留而权重与数据库仍被排除。

本地发布预检同时覆盖中文文件名：使用 Git 的 NUL 分隔输出核对文件集，避免中文路径被 Git 转义而被误判为缺文件。
