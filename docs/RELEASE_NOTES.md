# SoulX Studio 3.0.1 · Public developer preview

逐句修改、保留版本、批量文稿和长期声音资产。OING 的独立本地工作台，基于 Soul AI Lab / SoulX-Podcast；不代表上游官方发布。

## 本预发布包含

- 整理后的完整源码和已编译 TypeScript 前端。
- Mac Apple Silicon / Windows x64 在线安装入口；Intel Mac 仅工作台。
- 48 秒横、竖两版真实界面动效宣传片，音乐与效果音，无旁白。
- 公开核查说明、安装指南与附件 SHA-256。

## 先知道这些

这不是已签名/公证的稳定发行。目标电脑干净安装、真实粤语生成、显卡/内存表现仍需验证。首次安装需要网络，Python、推理依赖、模型权重不会全部内嵌。历史参考声音不是本轮模型输出；宣传片的任务和版本使用明确标注的测试音，不能用来判断语音质量。
