# SoulX Studio

**粤语声音生产工作台 · Cantonese Voice Workbench**

逐句编辑、保留配音版本、批量任务与可复用声音资产。OING 在 Soul-AILab/SoulX-Podcast 基础上开发的独立工作台，并非原模型官方客户端。

## 发布进度

公开仓库已建立，正在导入经过清理的源码、安装说明、Mac / Windows 安装预览包和项目宣传片。

**目前尚未提供经过验证的线上安装附件。请勿把 GitHub 的 “Code → Download ZIP” 当作软件安装包。**

导入和附件校验完成后，本页会提供对应系统的 Release 下载入口。

## 版本边界

本次为 Developer Preview：安装程序尚未完成发布者签名 / Apple 公证，Mac 与 Windows 的干净安装、真实粤语音质仍需实机验收。首次安装需要联网准备独立环境与模型；Intel Mac 仅开放工作台。

代码继承与修改遵循上游 Apache-2.0 许可；模型权重、第三方参考声音的许可分别适用。仅使用本人或获授权的参考声音。
